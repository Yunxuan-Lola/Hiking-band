# Reference materials

This directory preserves source material that is not part of the runnable system.

- `course_documents/` contains the original course requirements, design report and user manual PDFs.
- `firmware_drafts/` contains an earlier watch sketch; build `Watch/hikingassistant_RTOS/` for the running firmware.
- `experiments/` contains a synthetic-data training example. Use `RPi/train_public.py` for the documented model workflow.

The active project documentation is in [`docs/`](../docs/README.md).
